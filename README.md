# MAZE — интернет-магазин техники

Next.js фронтенд + Fastify API в одном репозитории.

| Часть | Папка |
|-------|-------|
| Сайт (Next.js) | `Client/` |
| API (Fastify) | `Server/` |
| Документация | `docs/` |

## Локальный запуск

**Сервер:**
```bash
cd Server && npm install && npm run dev
```

**Клиент:**
```bash
cd Client && npm install && cp .env.example .env.local && npm run dev
```
