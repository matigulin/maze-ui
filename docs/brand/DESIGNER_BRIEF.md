## Философия MAZE (прочитать первым)

1. **Если экран продаёт — brand. Если помогает выбрать и оформить — system.**
2. **Mesh и glow — только точечно** (splash, hero, редкие промо). Не декоративная система всего сайта.
3. **Эмоция вверху → ясность в товарной зоне → простота в checkout.**

**Воронка:** сначала цепляет атмосферой → убеждает товаром → не мешает оформить покупку.

---

## Brand vs System — где какой стиль

| Зона | Стиль | Примеры |
|------|--------|---------|
| **Brand** | Градиент, mesh, glow, кастомные карточки, выразительная типографика | Splash, hero главной, info strip, mixed grid promo, partner strip, footer accents |
| **Brand-lite** | Узнаваемый MAZE, но приоритет читаемости | Product card в сетке (hover, тени — умеренно) |
| **System** | Нейтральный UI: белый/серый фон, чёткая иерархия, формы | Каталог, PDP, корзина, checkout, ЛК, CMS-контент |
| **System strict** | Плотный рабочий интерфейс, без декора | Admin, manager |

**Правило:** текст на mesh/градиенте — только на **solid-подложке** или с контрастом WCAG AA.

## 4. Логотип — полная спецификация

### 4.1. Знаковая часть (символ «А» / лабиринт)

**Геометрия:**
- Три вложенных контура, повторяющих форму треугольника / шеврона (стрелка вверх).
- Линии **монолинейные** — одинаковая толщина по всему контуру.
- Углы и концы линий **слегка скруглены** (не острые 90°).
- Внешний контур — крупнейший; внутренние два — пропорционально уменьшены.
- Основание формы открытое (как у буквы А без горизонтальной перекладины в классическом смысле).
- Визуально: путь лабиринта, «гора», навигация вверх.

**Цвет в полноцветном SVG:**
- Радиальный градиент: `#005B92` → `#065287` → `#004E84` → `#024684`.
- Создаёт объём и глубину, не плоская заливка.

**Отдельный знак (icon only):**
- Использовать без wordmark для: favicon, app icon, splash (фаза 1), компактный header на mobile.
- Минимальный размер в UI: **24 × 24 px** (favicon 32px).
- Охранное поле: не менее **½ высоты знака** со всех сторон.

### 4.2. Wordmark «maze»

**Написание:** только **строчные** — `maze`, никогда `MAZE` в логотипе (в тексте сайта заголовки могут быть uppercase по стилю, но не в знаке).

**Характер (кастомный логотипный шрифт, не стандартный):**
- Широкий геометричный гротеск, «цифровой», tech.
- Горизонтально растянутые формы букв.
- Монолинейность — буквы как из линий равной толщины.
- Широкий трекинг между буквами.

**Анатомия букв (для воссоздания при необходимости):**

| Буква | Описание |
|-------|----------|
| **m** | Три вертикальных штриха + верхняя дуга; широкая, устойчивая форма |
| **a** | Округлый корпус с апертурой (вырез) слева внизу |
| **z** | Острый зигзаг / волна — самая динамичная буква |
| **e** | Округлый корпус + горизонтальная перекладина, не замыкающая контур справа |

**Градиенты по буквам (полноцветный SVG):**

| Буква | Тип градиента | Ключевые цвета |
|-------|---------------|----------------|
| m | Radial | `#041759` → `#020D53` |
| a | Linear | `#064882` → `#03256C` |
| z | Radial | `#054B87` → `#06659E` |
| e | Linear | `#008AB4` → `#066CA0` (самая светлая, cyan-акцент) |

Эффект: слово **переливается** слева направо от глубокого navy к бирюзе.

### 4.3. Версии компоновки

| ID | Название | Расположение | Применение |
|----|----------|--------------|------------|
| L-H | Horizontal | Знак слева, `maze` справа | Header desktop, документы, OG |
| L-V | Vertical | Знак сверху по центру, `maze` снизу | Splash, footer, mobile hero, соцсети |
| L-I | Icon only | Только лабиринт | Favicon, loader фаза 1, compact header |

**Пропорции (ориентир):**
- Horizontal `Frame 1171280515.svg`: ~2.7 : 1 (ширина к высоте).
- Знак ≈ 40% ширины lockup, wordmark ≈ 60%.

### 4.4. Цветность логотипа

| ID | Фон | Логотип | Когда |
|----|-----|---------|-------|
| L1 | Белый / светло-серый `#F5F5F7` | Чёрный `#000000` mono | Светлые секции, каталог, карточки |
| L2 | Чёрный `#000000` / navy `#000046` | Белый `#FFFFFF` mono | Тёмный hero, footer |
| L3 | Любой | Полноцветный градиентный SVG | Hero, splash, marketing |
| L4 | Фото / mesh gradient | Белый mono + subtle shadow | Поверх интерактивного фона |

**Запрещено:**
- Менять пропорции знака и wordmark.
- Добавлять обводку, тень, glow без согласования.
- Размещать градиентный логотип на пёстром фоне без подложки.
- Использовать цвета вне палитры бренда.

### 4.5. Минимальные размеры

| Версия | Print | Digital (min height) |
|--------|-------|---------------------|
| Horizontal | 30 mm | 32 px |
| Vertical | 25 mm | 40 px |
| Icon only | 15 mm | 24 px |

### 5.3. Фирменные градиенты (обязательно в Figma как styles)

**Gradient 1 — Primary (Deep → Cyan):**
```
#000046  →  #1CB5E0
Direction: 135° (или left-to-right на hero)
```
Основной фон hero, mesh gradient, CTA hover.

**Gradient 2 — Royal Pair:**
```
#1488CC  →  #2B32B2
Direction: 90°
```
Промо-блоки, secondary buttons, акцентные полосы.

**Gradient 3 — Sky to White (секционный мост):**
```
#2980B9  →  #6DD5FA  →  #FFFFFF
Direction: top-to-bottom
```
Переход тёмной секции к светлой (gradient bridge между блоками).

**Gradient 4 — Logo wordmark (reference only):**
Многостоповые градиенты на буквах — см. §4.2, не дублировать на UI-элементах.

### 5.4. Семантические цвета UI

| Token | HEX | Использование |
|-------|-----|---------------|
| `success` | `#34C759` | Заказ оформлен, в наличии |
| `warning` | `#FF9500` | Мало на складе, внимание |
| `error` | `#FF3B30` | Ошибка формы, нет в наличии |
| `info` | `#1CB5E0` | Информационные баннеры (= brand cyan) |

### 5.5. Правила применения цвета

1. **60%** нейтраль (чёрный/белый/серый) · **30%** navy/blue · **10%** cyan accent.
2. На одном экране — **не более 2 градиентов** одновременно.
3. Текст на градиенте — только белый; проверить контраст WCAG AA.
4. Каталог и PDP — **преимущественно светлый фон** (SEO, читаемость, фото товаров).
5. Cyan glow / неон — **только** hero, splash, интерактивный фон; не на формах.

## 6. Типографика

### 6.1. Что есть в бренде

Кастомный **логотипный** шрифт `maze` — только в составе знака. **Не использовать как UI-шрифт.**

### 6.2. Что нужно предложить дизайнеру

Предложить пару и согласовать. Ниже — **рекомендация по направлению** (не финал):

| Роль | Рекомендация | Альтернативы | Характер |
|------|--------------|--------------|----------|
| **Display / H1–H2** | Кастом на базе wide geometric sans | Monument Extended, Syne, Outfit (700, wide tracking) | Tech, премиум, как wordmark |
| **Body** | Inter или Manrope | SF Pro, Geist | Нейтральный, читаемый |
| **UI / кнопки** | Тот же body, medium weight | — | 14–16px |
| **Цены** | Body, tabular nums | `font-variant-numeric: tabular-nums` | Выравнивание в корзине |
| **Мелкий текст** | Body 12–13px | legal, captions | gray-600 |

### 6.3. Шкала типографики (desktop)

| Token | Size | Weight | Line-height | Letter-spacing | Пример |
|-------|------|--------|-------------|----------------|--------|
| `display-xl` | 72px | 700 | 1.0 | -0.02em | Hero MAZE |
| `display-lg` | 48px | 700 | 1.1 | -0.01em | H1 страницы |
| `heading-1` | 36px | 600 | 1.2 | 0 | Раздел каталога |
| `heading-2` | 28px | 600 | 1.25 | 0 | H2 секции |
| `heading-3` | 22px | 600 | 1.3 | 0 | H3 карточки |
| `body-lg` | 18px | 400 | 1.5 | 0 | Lead text |
| `body` | 16px | 400 | 1.5 | 0 | Основной текст |
| `body-sm` | 14px | 400 | 1.45 | 0 | UI labels |
| `caption` | 12px | 400 | 1.4 | 0.02em | Подписи, legal |
| `overline` | 11px | 600 | 1.3 | 0.15em | «СКРОЛЛ», labels uppercase |

### 6.4. Mobile — масштаб

| Desktop | Mobile |
|---------|--------|
| display-xl 72px | 40px |
| display-lg 48px | 32px |
| heading-1 36px | 28px |
| body 16px | 15px |

### 6.5. Правила текста (от заказчика)

- **Лаконично.** Без воды и маркетингового шума.
- Заголовки — короткие (3–6 слов).
- CTA — глагол + объект: «Перейти в каталог», «Рассчитать трейд-ин».
- Цены — с разделителем тысяч: `129 990 ₽`.
- Телефон — `+7 (995) 911-49-84`.

## 7. Графические элементы и паттерны

### 7.1. Кольца («пончики») — из брендбука

- Толстые чёрные кольца с пустым центром.
- Разный масштаб, частично обрезаны краем.
- **Использование:** декоративный паттерн hero (opacity 5–15%), фоновые элементы, **не** под текстом мелкого размера.

### 7.2. Лабиринт / шеврон

- Упрощённый знак без wordmark.
- Loader, favicon, watermark, разделители.

### 7.3. Неон / glow (offline-референс)

- Cyan glow `#1CB5E0` с blur 20–40px, opacity 30–50%.
- Только на тёмном: hero, hover logo, интерактивный фон.
- **Не** имитировать неон на каждой кнопке.

### 7.4. Gradient bridge (переход секций)

Между тёмной и светлой секцией — полоса 80–120px высотой с Gradient 3 (`#2980B9 → #6DD5FA → #FFFFFF`).  
Референс: sweetpunk.com — плавный переход без резкой линии.

### 7.5. Partner brands strip

- Логотипы Apple, Samsung, Dyson, Marshall, Sony, Harman — **одна цветовая гамма**.
- Monochrome: `#FFFFFF` opacity 50% на тёмном / `#000000` opacity 40% на светлом.
- Hover: opacity 100%.
- Высота логотипа в полосе: 24–32px.

## 8. Интерактивный фон (mesh gradient)

### 8.1. Референс

**[ailogogenerator.online](https://ailogogenerator.online/)** — hero с мягким **mesh / aurora gradient**, который:
- медленно **движется сам** (autonomous drift), даже без курсора;
- **реагирует на мышь** — цветовые «пятна» смещаются / текут за курсором;
- тёмная база + 2–4 цветовых anchor (blob);
- лёгкий **film grain** (шум) для тактильности;
- контент (заголовок, форма, CTA) — **поверх** на чистом слое, читаемость 100%.

Дополнительный референс по характеру: **sweetpunk.com** — liquid gradient + mouse interaction.

### 8.2. Адаптация под MAZE

**Цвета mesh (4 anchor points):**

| Anchor | HEX | Роль |
|--------|-----|------|
| A1 | `#000046` | База, глубина |
| A2 | `#041759` | Navy blob |
| A3 | `#1CB5E0` | Primary cyan — следует за курсором |
| A4 | `#2980B9` | Secondary blue |

**Параметры (для motion-спеки в Figma / dev handoff):**

| Параметр | Значение | Описание |
|----------|----------|----------|
| `speed` | 0.2–0.4 | Скорость автономного дрейфа |
| `mouseInfluence` | 0.4–0.6 | Насколько курсор тянет blob |
| `lag` | 80–150ms | Инерция следования за мышью |
| `grain` | 3–5% opacity | Film grain overlay |
| `blur` | 80–120px | Размытие blob (feGaussianBlur эквивалент) |
| `ripple on click` | опционально | Лёгкая рябь при клике (как Aurora Mesh) |

### 8.3. Где использовать интерактивный фон

| Страница / зона | Интерактивный mesh | Статичный фон |
|-----------------|-------------------|---------------|
| **Hero главной** | ✅ Да | — |
| **Splash / preloader** | ✅ Да (упрощённый) | — |
| **Footer (верхняя часть)** | ⚠️ Опционально, subtle | ✅ |
| **О нас / CMS** | ⚠️ Только hero-блок страницы | ✅ Основной контент |
| **Каталог, список** | ❌ Нет | ✅ Белый / gray-50 |
| **Карточка товара (PDP)** | ❌ Нет | ✅ Белый (фото товара — герой) |
| **Корзина, checkout** | ❌ Нет | ✅ Нейтральный, фокус на форме |
| **Личный кабинет** | ❌ Нет | ✅ Светлый |
| **Admin / manager** | ❌ Нет | ✅ Нейтральный UI |
| **404 / empty states** | ⚠️ Опционально | — |

**Принцип:** интерактивный фон — **«вау» на входе**, не на каждой странице. Иначе: устаёт, падает производительность, страдает SEO на контентных страницах.

### 8.4. Fallback (обязательно в макете)

Прописать состояние **«без WebGL / reduced motion»:**
- Статичный CSS gradient: `#000046` → `#041759` (135°).
- Без анимации.
- `prefers-reduced-motion: reduce` — отключить drift и mouse follow.

### 8.5. Слои (z-index) для hero с mesh

```
z-0:  Mesh gradient canvas (fullscreen, position fixed или absolute)
z-1:  Optional grain overlay
z-2:  Optional vignette (radial gradient darken edges)
z-10: Content (logo, H1, CTA, scroll indicator)
z-20: Header (transparent → solid on scroll)
```

### 8.6. Макет для дизайнера

В Figma:
1. Frame «Hero — Interactive BG» с **имитацией** mesh (blur blobs, не обязательно real-time).
2. Отдельный frame «Hero — Static Fallback».
3. Annotation layer с параметрами §8.2.
4. Storyboard: 3 кадра — idle / mouse left / mouse right.

## 12. Анимации и motion

### 12.1. Splash / Preloader (обязательный storyboard)

**Длительность:** 2.5–3.5 сек (первый визит) или skip.

| Фаза | Время | Действие |
|------|-------|----------|
| 1 | 0–1.2s | Фон тёмный + mesh subtle. Лабиринт рисуется stroke-draw (линии по очереди, снизу вверх или от внешнего к внутреннему) |
| 2 | 1.2–2.0s | Wordmark `maze` fade + slight scale up (0.95 → 1). Опционально: градиентный перелив запускается |
| 3 | 2.0–2.8s | Progress bar тонкая cyan внизу (опционально) |
| 4 | 2.8–3.2s | Fade out всего splash → hero |

**Фон splash:** тот же mesh gradient, приглушённый.

### 12.2. Logo animation (на сайте после splash)

- **Idle:** медленный перелив градиента на буквах (6–8s loop).
- **On scroll:** лёгкое изменение gradient offset (опционально).
- **Hover:** subtle glow cyan.

### 12.3. Секции и карточки

| Элемент | Анимация | Длительность |
|---------|----------|--------------|
| Product card hover | scale 1.02, shadow | 300ms ease |
| Promo banner hover | image scale 1.05 | 500ms ease |
| Section fade-in on scroll | opacity + translateY 20px | 600ms, once |
| Info carousel | slide horizontal, autoplay 5s | — |
| Accordion specs | height + chevron rotate | 250ms |

### 12.4. Page transitions

- Между страницами: без тяжёлых transition (Next.js default).
- Внутри checkout steps: horizontal slide или fade 200ms.

### 12.5. Reduced motion

Все анимации §12 — отключать при `prefers-reduced-motion`. В Figma: отдельная пометка.

## 18. What not to do

- Не растягивать mesh / liquid gradient на каталог, PDP, корзину, checkout, ЛК.
- Не делать неон и glow на формах, в админке и manager.
- Не использовать логотипный шрифт `maze` для body, цен и UI.
- Не добавлять цвета вне палитры брифа (§5).
- Не делать весь сайт «анимационным шоу» — motion только где указано (§12).
- Не прятать цену, наличие и CTA «В корзину» ниже fold на mobile PDP.
- Не копировать iostrade / sweetpunk **визуально** — только структуру блоков.
- Не размещать мелкий текст прямо на mesh без подложки.
- Не ставить 3D / WebGL на PDP и в каталоге.
- Не смешивать brand-hero и system-формы на одном экране без явной границы секций.
- Не делать dark mode toggle в MVP.
- Не более **одного primary CTA** на экран.
